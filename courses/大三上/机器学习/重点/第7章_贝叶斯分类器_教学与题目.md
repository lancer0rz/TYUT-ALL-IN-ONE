# 第 7 章：贝叶斯分类器 (Bayesian Classifiers)

## 一、核心概念详解

### 1.1 贝叶斯定理基础

#### 贝叶斯公式

$$P(c|x) = \frac{P(x|c)P(c)}{P(x)}$$

其中：
- $P(c|x)$：**后验概率**，给定样本 $x$ 时类别为 $c$ 的概率
- $P(x|c)$：**类条件概率/似然**，类别 $c$ 产生样本 $x$ 的概率
- $P(c)$：**先验概率**，类别 $c$ 的概率
- $P(x)$：**证据**，样本 $x$ 的概率

#### 贝叶斯决策论

对于所有可能的类别 $c \in \mathcal{Y}$，选择后验概率最大的类别：

$$h^*(x) = \arg\max_{c \in \mathcal{Y}} P(c|x)$$

由于 $P(x)$ 对所有类别相同，决策可以简化为：

$$h^*(x) = \arg\max_{c \in \mathcal{Y}} P(x|c)P(c)$$

## 二、朴素贝叶斯分类器 (Naive Bayes) ⭐作业重点

### 2.1 核心假设：属性条件独立性

**假设**：在给定类别 $c$ 的条件下，各属性之间**相互独立**。

$$P(x|c) = P(x_1, x_2, ..., x_d|c) = \prod_{i=1}^{d}P(x_i|c)$$

这是一个很强的假设，现实中很少完全成立，但实践证明效果很好。

### 2.2 朴素贝叶斯分类器

基于贝叶斯定理和条件独立假设：

$$h_{nb}(x) = \arg\max_{c \in \mathcal{Y}} P(c)\prod_{i=1}^{d}P(x_i|c)$$

**决策过程**：
1. 对每个类别 $c$，计算 $P(c)\prod_{i=1}^{d}P(x_i|c)$
2. 选择值最大的类别

### 2.3 参数估计

#### 先验概率 $P(c)$

$$P(c) = \frac{|D_c|}{|D|}$$

其中 $D_c$ 是类别 $c$ 的样本集合。

#### 类条件概率 $P(x_i|c)$

**离散属性**：

$$P(x_i|c) = \frac{|D_{c,x_i}|}{|D_c|}$$

其中 $D_{c,x_i}$ 是类别 $c$ 中属性 $i$ 取值为 $x_i$ 的样本集合。

**连续属性**：

假设属性服从高斯分布：

$$P(x_i|c) = \frac{1}{\sqrt{2\pi}\sigma_{c,i}}\exp\left(-\frac{(x_i - \mu_{c,i})^2}{2\sigma_{c,i}^2}\right)$$

其中 $\mu_{c,i}$ 和 $\sigma_{c,i}^2$ 是类别 $c$ 中属性 $i$ 的均值和方差。

### 2.4 拉普拉斯平滑

**问题**：如果某个属性值在训练集中没有出现过，会导致 $P(x_i|c) = 0$，使整个乘积为0。

**解决**：拉普拉斯修正（Laplace Smoothing）

$$\hat{P}(c) = \frac{|D_c| + 1}{|D| + N}$$

$$\hat{P}(x_i|c) = \frac{|D_{c,x_i}| + 1}{|D_c| + N_i}$$

其中：
- $N$ 是类别数
- $N_i$ 是属性 $i$ 的可能取值数

### 2.5 朴素贝叶斯分类示例

**训练数据**：

| 编号 | 天气 | 温度 | 玩耍 |
|------|------|------|------|
| 1 | 晴 | 热 | 否 |
| 2 | 晴 | 热 | 否 |
| 3 | 阴 | 热 | 是 |
| 4 | 雨 | 适中 | 是 |
| 5 | 雨 | 凉 | 是 |
| 6 | 雨 | 凉 | 否 |
| 7 | 阴 | 凉 | 是 |
| 8 | 晴 | 适中 | 否 |
| 9 | 晴 | 凉 | 是 |
| 10 | 雨 | 适中 | 是 |

**预测**：天气=晴，温度=凉 → 玩耍?

**计算步骤**：

1. 先验概率：
   - $P(是) = 6/10 = 0.6$
   - $P(否) = 4/10 = 0.4$

2. 类条件概率：
   - $P(晴|是) = 2/6$，$P(晴|否) = 3/4$
   - $P(凉|是) = 3/6$，$P(凉|否) = 1/4$

3. 计算后验：
   - $P(是) \times P(晴|是) \times P(凉|是) = 0.6 \times (2/6) \times (3/6) = 0.1$
   - $P(否) \times P(晴|否) \times P(凉|否) = 0.4 \times (3/4) \times (1/4) = 0.075$

4. 决策：$0.1 > 0.075$，预测为"是"

## 三、半朴素贝叶斯分类器

### 3.1 动机

朴素贝叶斯的**属性独立假设过于严格**，现实中属性之间往往存在依赖关系。

**半朴素贝叶斯**：适当考虑一部分属性间的依赖关系。

### 3.2 独依赖估计 (ODE)

**One-Dependent Estimator**：假设每个属性最多只依赖于一个其他属性（称为**父属性**）。

$$P(c|x) \propto P(c)\prod_{i=1}^{d}P(x_i|c, pa_i)$$

其中 $pa_i$ 是属性 $x_i$ 的父属性。

### 3.3 常见方法

#### SPODE (Super-Parent ODE)

假设所有属性都依赖于同一个父属性（超父）：

$$P(c|x) \propto P(c)P(x_{sp}|c)\prod_{i=1}^{d}P(x_i|c, x_{sp})$$

其中 $x_{sp}$ 是超父属性。

#### AODE (Averaged ODE)

将每个属性都作为超父，取平均：

$$P(c|x) \propto \sum_{i=1, |D_{x_i}| \geq m'}^{d} P(c, x_i)\prod_{j=1}^{d}P(x_j|c, x_i)$$

**优点**：无需选择超父，性能稳定。

#### TAN (Tree Augmented Naive Bayes)

在条件独立结构上增加一棵**树形结构**来表示属性间的依赖关系。

构建步骤：
1. 计算任意两个属性间的条件互信息
2. 构建完全图，以条件互信息为边权
3. 构建最大权生成树
4. 选择根节点，将边变为有向边

## 四、朴素贝叶斯的优缺点

### 优点
1. **简单高效**：计算复杂度低
2. **少量数据**：在小数据集上表现好
3. **多分类**：天然支持多分类
4. **增量学习**：可以方便地进行增量学习
5. **可解释**：概率含义明确

### 缺点
1. **独立性假设**：属性独立假设往往不成立
2. **零概率问题**：需要平滑处理
3. **数值属性**：需要假设分布形式
