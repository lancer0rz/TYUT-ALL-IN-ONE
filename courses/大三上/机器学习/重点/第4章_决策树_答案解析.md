## 选择题答案

### 第1题
**答案：C**

**解析**：
数据集D：100个样本，60正40负

$$Ent(D) = -\frac{60}{100}\log_2\frac{60}{100} - \frac{40}{100}\log_2\frac{40}{100}$$
$$= -0.6\log_2 0.6 - 0.4\log_2 0.4$$

计算：
- $\log_2 0.6 = \frac{\ln 0.6}{\ln 2} ≈ -0.737$
- $\log_2 0.4 = \frac{\ln 0.4}{\ln 2} ≈ -1.322$

$$Ent(D) = -0.6 \times (-0.737) - 0.4 \times (-1.322)$$
$$= 0.442 + 0.529 ≈ 0.97$$

### 第5题
**答案：A**

**解析**：
如果所有样本属于同一类（设为类k），则 $p_k = 1$，其他类 $p_{k'} = 0$

$$Ent(D) = -1 \times \log_2 1 - 0 \times \log_2 0 = 0$$

约定 $0\log_2 0 = 0$

完全纯净的样本集信息熵为0，这是信息熵的最小值。

- 分支过多，树过深
- 把训练数据中的噪声和异常也学习进去

## 判断题答案

### 第8题
**答案：错误 ✗**

**解析**：
信息熵与纯度的关系是**相反**的：
- 信息熵**越大**，不确定性越高，纯度**越低**
- 信息熵**越小**，不确定性越低，纯度**越高**
- 最纯净（单一类别）时，熵 = 0

---

### 第9题
**答案：正确 ✓**

**解析**：
信息增益的计算：$Gain(D,a) = Ent(D) - \sum\frac{|D^v|}{|D|}Ent(D^v)$

属性取值越多，划分越细，每个子集越纯净，加权平均熵越小，信息增益越大。

极端情况：如果用"编号"作为属性，每个样本一个分支，信息增益最大但毫无意义。

这就是为什么C4.5引入信息增益率来修正这个问题。

---

### 第10题
**答案：错误 ✗**

**解析**：
**离散属性**在决策树中通常只使用一次（用过就从属性集中删除）。

但**连续属性**可以在树的不同层多次使用，因为每次可以选择不同的划分点。

例如"年龄"属性可以先按30岁划分，然后在子树中再按50岁划分。

---

### 第11题
**答案：正确 ✓**

**解析**：
后剪枝的步骤：
1. 先生成一棵**完整的决策树**（可能过拟合）
2. 自底向上考察每个非叶节点
3. 如果将其替换为叶节点能提升验证集性能，则剪枝

因此必须先有完整的树才能进行后剪枝。

---

### 第12题
**答案：正确 ✓**

**解析**：
基尼值 $Gini(D) = 1 - \sum p_k^2$

- 当所有样本属于同一类时，$Gini = 1 - 1^2 = 0$（最小）
- 当样本均匀分布时，$Gini$ 最大

基尼值越小 → 纯度越高

这与信息熵的性质一致（熵越小 → 纯度越高）。

## 计算题答案

### 计算题 1

**数据统计**：
- 总样本：6个（3正3负）
- 色泽：青绿3个，乌黑3个
- 根蒂：蜷缩2个，稍蜷2个，硬挺2个

**(1) 计算整个数据集的信息熵**

$$Ent(D) = -\frac{3}{6}\log_2\frac{3}{6} - \frac{3}{6}\log_2\frac{3}{6}$$
$$= -\frac{1}{2}\log_2\frac{1}{2} - \frac{1}{2}\log_2\frac{1}{2}$$
$$= -\frac{1}{2} \times (-1) - \frac{1}{2} \times (-1)$$
$$= 0.5 + 0.5 = \boxed{1}$$

**(2) 计算属性"色泽"的信息增益**

按色泽划分：
- 青绿：{1是, 4否, 6否} → 1正2负
- 乌黑：{2是, 3是, 5否} → 2正1负

计算各子集的熵：

$$Ent(D_{青绿}) = -\frac{1}{3}\log_2\frac{1}{3} - \frac{2}{3}\log_2\frac{2}{3}$$
$$≈ 0.528 + 0.390 = 0.918$$

$$Ent(D_{乌黑}) = -\frac{2}{3}\log_2\frac{2}{3} - \frac{1}{3}\log_2\frac{1}{3}$$
$$≈ 0.390 + 0.528 = 0.918$$

信息增益：
$$Gain(D, 色泽) = Ent(D) - \frac{3}{6}Ent(D_{青绿}) - \frac{3}{6}Ent(D_{乌黑})$$
$$= 1 - 0.5 \times 0.918 - 0.5 \times 0.918$$
$$= 1 - 0.918 = \boxed{0.082}$$

**(3) 计算属性"根蒂"的信息增益**

按根蒂划分：
- 蜷缩：{1是, 2是} → 2正0负
- 稍蜷：{3是, 6否} → 1正1负
- 硬挺：{4否, 5否} → 0正2负

计算各子集的熵：

$$Ent(D_{蜷缩}) = -1\log_2 1 - 0\log_2 0 = 0$$

$$Ent(D_{稍蜷}) = -\frac{1}{2}\log_2\frac{1}{2} - \frac{1}{2}\log_2\frac{1}{2} = 1$$

$$Ent(D_{硬挺}) = -0\log_2 0 - 1\log_2 1 = 0$$

信息增益：
$$Gain(D, 根蒂) = 1 - \frac{2}{6} \times 0 - \frac{2}{6} \times 1 - \frac{2}{6} \times 0$$
$$= 1 - 0 - \frac{1}{3} - 0 = \boxed{0.667}$$

**(4) 选择根节点属性**

比较信息增益：
- Gain(D, 色泽) = 0.082
- Gain(D, 根蒂) = 0.667

$Gain(D, 根蒂) > Gain(D, 色泽)$

**选择"根蒂"作为根节点**

### 计算题 2

**数据**：8个样本，5正3负

**(1) 计算信息熵**

$$Ent(D) = -\frac{5}{8}\log_2\frac{5}{8} - \frac{3}{8}\log_2\frac{3}{8}$$

计算：
- $\log_2\frac{5}{8} = \log_2 0.625 ≈ -0.678$
- $\log_2\frac{3}{8} = \log_2 0.375 ≈ -1.415$

$$Ent(D) = -0.625 \times (-0.678) - 0.375 \times (-1.415)$$
$$= 0.424 + 0.531 = \boxed{0.955}$$

**(2) 计算基尼值**

$$Gini(D) = 1 - \left(\frac{5}{8}\right)^2 - \left(\frac{3}{8}\right)^2$$
$$= 1 - \frac{25}{64} - \frac{9}{64}$$
$$= 1 - \frac{34}{64} = \frac{30}{64} = \boxed{0.469}$$

**(3) 计算划分后的加权基尼指数**

子集$D^1$（3正1负，共4个）：
$$Gini(D^1) = 1 - \left(\frac{3}{4}\right)^2 - \left(\frac{1}{4}\right)^2 = 1 - \frac{9}{16} - \frac{1}{16} = \frac{6}{16} = 0.375$$

子集$D^2$（2正2负，共4个）：
$$Gini(D^2) = 1 - \left(\frac{2}{4}\right)^2 - \left(\frac{2}{4}\right)^2 = 1 - \frac{1}{4} - \frac{1}{4} = 0.5$$

加权基尼指数：
$$Gini\_index = \frac{4}{8} \times 0.375 + \frac{4}{8} \times 0.5$$
$$= 0.5 \times 0.375 + 0.5 \times 0.5$$
$$= 0.1875 + 0.25 = \boxed{0.4375}$$

### 计算题 3

**数据排序**：
| 编号 | 密度 | 好瓜 |
|------|------|------|
| 6 | 0.403 | 否 |
| 5 | 0.556 | 否 |
| 4 | 0.608 | 否 |
| 3 | 0.634 | 是 |
| 1 | 0.697 | 是 |
| 2 | 0.774 | 是 |

总体：6个样本，3正3负，$Ent(D) = 1$

**(1) 列出候选划分点**

相邻值的中点：

$$T = \left\{\frac{0.403+0.556}{2}, \frac{0.556+0.608}{2}, \frac{0.608+0.634}{2}, \frac{0.634+0.697}{2}, \frac{0.697+0.774}{2}\right\}$$

$$T = \boxed{\{0.480, 0.582, 0.621, 0.666, 0.736\}}$$

**(2) 计算每个划分点的信息增益**

**t = 0.480**
- $D^-$：{6} → 0正1负，$Ent = 0$
- $D^+$：{5,4,3,1,2} → 3正2负

$$Ent(D^+) = -\frac{3}{5}\log_2\frac{3}{5} - \frac{2}{5}\log_2\frac{2}{5} ≈ 0.971$$

$$Gain = 1 - \frac{1}{6} \times 0 - \frac{5}{6} \times 0.971 = 1 - 0.809 = 0.191$$

**t = 0.582**
- $D^-$：{6,5} → 0正2负，$Ent = 0$
- $D^+$：{4,3,1,2} → 3正1负

$$Ent(D^+) = -\frac{3}{4}\log_2\frac{3}{4} - \frac{1}{4}\log_2\frac{1}{4} ≈ 0.811$$

$$Gain = 1 - \frac{2}{6} \times 0 - \frac{4}{6} \times 0.811 = 1 - 0.541 = 0.459$$

**t = 0.621** ⭐
- $D^-$：{6,5,4} → 0正3负，$Ent = 0$
- $D^+$：{3,1,2} → 3正0负，$Ent = 0$

$$Gain = 1 - \frac{3}{6} \times 0 - \frac{3}{6} \times 0 = 1$$

**t = 0.666**
- $D^-$：{6,5,4,3} → 1正3负

$$Ent(D^-) = -\frac{1}{4}\log_2\frac{1}{4} - \frac{3}{4}\log_2\frac{3}{4} ≈ 0.811$$

- $D^+$：{1,2} → 2正0负，$Ent = 0$

$$Gain = 1 - \frac{4}{6} \times 0.811 - \frac{2}{6} \times 0 = 1 - 0.541 = 0.459$$

**t = 0.736**
- $D^-$：{6,5,4,3,1} → 2正3负

$$Ent(D^-) = -\frac{2}{5}\log_2\frac{2}{5} - \frac{3}{5}\log_2\frac{3}{5} ≈ 0.971$$

- $D^+$：{2} → 1正0负，$Ent = 0$

$$Gain = 1 - \frac{5}{6} \times 0.971 - \frac{1}{6} \times 0 = 1 - 0.809 = 0.191$$

**信息增益汇总**：

| 划分点 | 信息增益 |
|--------|----------|
| 0.480 | 0.191 |
| 0.582 | 0.459 |
| **0.621** | **1.000** |
| 0.666 | 0.459 |
| 0.736 | 0.191 |

**(3) 最优划分点**

$$\boxed{t = 0.621}$$

此划分点完美分开了正负例（信息增益 = 1，即完全消除了不确定性）。

划分规则：
- 密度 ≤ 0.621 → 坏瓜
- 密度 > 0.621 → 好瓜
