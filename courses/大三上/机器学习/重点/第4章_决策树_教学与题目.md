# 第 4 章：决策树 (Decision Trees)

## 一、核心概念详解

### 1.1 基本概念

#### 什么是决策树？

决策树是一种基于树结构进行决策的分类/回归模型：
- **内部节点**：对应属性测试
- **分支**：对应测试结果
- **叶节点**：对应类别标签或数值

**从根到叶的路径**对应一条**决策规则**。

```
           [天气]
          /  |  \
       晴   阴   雨
       /    |     \
    [湿度] 打球  [风力]
    /  \         /  \
  高  正常     强   弱
  |    |       |    |
不打球 打球  不打球 打球
```

### 1.2 决策树的构建流程

**递归过程**（分而治之）：

```
函数 TreeGenerate(D, A):
    生成节点 node
    if D中样本都属于同一类别C:
        将node标记为C类叶节点
        return
    if A = ∅ OR D中样本在A上取值相同:
        将node标记为D中最多类的叶节点
        return
    
    从A中选择最优划分属性 a*
    for a*的每个值 av:
        为node生成分支
        Dv = D中在a*上取值为av的样本子集
        if Dv为空:
            分支标记为D中最多类的叶节点
        else:
            分支节点 = TreeGenerate(Dv, A\{a*})
    return node
```

**三种停止条件**：
1. 当前节点所有样本属于同一类
2. 当前属性集为空，或所有样本在属性上取值相同
3. 当前节点样本集为空

## 二、划分选择 ⭐重点公式

### 2.1 信息熵 (Information Entropy)

**定义**：度量样本集合**纯度**的指标

$$Ent(D) = -\sum_{k=1}^{|y|}p_k\log_2p_k$$

其中：
- $|y|$ 是类别数
- $p_k$ 是第 $k$ 类样本在 $D$ 中所占的比例

**性质**：
- $Ent(D) \geq 0$
- $Ent(D)$ 越小，纯度越高
- 当所有样本属于同一类时，$Ent(D) = 0$
- 当样本均匀分布时，$Ent(D)$ 最大

**约定**：$0\log_2 0 = 0$

**示例**：
假设数据集D有10个样本，6正4负：

$$Ent(D) = -\frac{6}{10}\log_2\frac{6}{10} - \frac{4}{10}\log_2\frac{4}{10}$$
$$= -0.6\log_2 0.6 - 0.4\log_2 0.4$$
$$≈ 0.971$$

### 2.2 信息增益 (Information Gain) ⭐核心

**定义**：使用属性 $a$ 进行划分所获得的**纯度提升**

$$Gain(D, a) = Ent(D) - \sum_{v=1}^{V}\frac{|D^v|}{|D|}Ent(D^v)$$

其中：
- $V$ 是属性 $a$ 的取值数
- $D^v$ 是 $D$ 中属性 $a$ 取值为 $a^v$ 的样本子集
- $\frac{|D^v|}{|D|}$ 是子集的权重

**理解**：
- 信息增益 = 划分前的熵 - 划分后的加权平均熵
- 信息增益越大，使用该属性划分效果越好

**ID3算法**：选择信息增益最大的属性进行划分

### 2.3 信息增益比 (Gain Ratio)

**问题**：信息增益偏向取值较多的属性

**解决**：使用增益率

$$Gain\_ratio(D, a) = \frac{Gain(D, a)}{IV(a)}$$

其中**固有值**：

$$IV(a) = -\sum_{v=1}^{V}\frac{|D^v|}{|D|}\log_2\frac{|D^v|}{|D|}$$

**注意**：增益率偏向取值较少的属性

**C4.5算法**：先选信息增益高于平均水平的属性，再从中选增益率最高的

### 2.4 基尼指数 (Gini Index)

**基尼值**：

$$Gini(D) = \sum_{k=1}^{|y|}\sum_{k'\neq k}p_kp_{k'} = 1 - \sum_{k=1}^{|y|}p_k^2$$

**理解**：从D中随机抽取两个样本，类别不一致的概率

**基尼指数**：

$$Gini\_index(D, a) = \sum_{v=1}^{V}\frac{|D^v|}{|D|}Gini(D^v)$$

**CART算法**：选择基尼指数最小的属性进行划分

## 三、剪枝处理 ⭐重点

### 3.1 为什么要剪枝？

**目的**：抑制过拟合，提高泛化能力

决策树完全生长可能：
- 把训练数据学得太好
- 把噪声也学进去了
- 泛化能力差

### 3.2 预剪枝 (Pre-pruning)

**策略**：在构建树的过程中提前停止

**方法**：在划分前估计，如果划分不能带来泛化性能提升，则停止划分，将当前节点设为叶节点。

**优点**：
- 降低过拟合风险
- 减少训练时间和测试时间

**缺点**：
- 可能导致欠拟合
- 有些分支虽然当前不能提升性能，但后续划分可能有用

### 3.3 后剪枝 (Post-pruning)

**策略**：先完全生成决策树，再自底向上地剪枝

**方法**：考察每个非叶节点，如果将其替换为叶节点能提升泛化性能，则进行替换。

**优点**：
- 欠拟合风险小
- 泛化性能通常优于预剪枝

**缺点**：
- 训练时间开销大（需先生成完整树）

| 对比 | 预剪枝 | 后剪枝 |
|------|--------|--------|
| 时机 | 边建边剪 | 建完再剪 |
| 时间开销 | 小 | 大 |
| 欠拟合风险 | 较高 | 较低 |
| 泛化性能 | 可能较差 | 通常较好 |

## 四、连续值与缺失值

### 4.1 连续值处理

**问题**：连续属性可能有无穷多个值

**解决**：二分法（C4.5采用）

**步骤**：
1. 将属性 $a$ 的 $n$ 个取值从小到大排序：$\{a^1, a^2, ..., a^n\}$
2. 取相邻值的中点作为候选划分点：$T_a = \{\frac{a^i + a^{i+1}}{2} | 1 \leq i \leq n-1\}$
3. 选择最优划分点（使信息增益最大）

$$Gain(D, a) = \max_{t \in T_a} Ent(D) - \left[\frac{|D_t^-|}{|D|}Ent(D_t^-) + \frac{|D_t^+|}{|D|}Ent(D_t^+)\right]$$

其中：
- $D_t^-$：属性 $a$ 取值 $\leq t$ 的样本
- $D_t^+$：属性 $a$ 取值 $> t$ 的样本

**注意**：连续属性可在树的不同层重复使用

### 4.2 缺失值处理

**两个问题**：
1. 如何计算有缺失值的属性的信息增益？
2. 已选属性上样本值缺失，如何划分？

**解决方案**（C4.5）：

设 $\tilde{D}$ 为属性 $a$ 上无缺失值的样本子集

$$\rho = \frac{|\tilde{D}|}{|D|}$$

使用 $\tilde{D}$ 计算信息增益，然后乘以 $\rho$：

$$Gain(D, a) = \rho \times Gain(\tilde{D}, a)$$

对于缺失值样本：
- 按概率划入各个分支
- 权重调整为原权重乘以该分支的样本比例
