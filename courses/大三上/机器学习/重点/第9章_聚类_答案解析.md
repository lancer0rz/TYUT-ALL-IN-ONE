# 第 9 章：聚类 - 答案解析

## 选择题答案

### 第1题
**答案：B**

**解析**：
K-means算法中，簇的中心（也称质心或均值向量）是由**簇中所有点的均值**决定的：

$$\mu_i = \frac{1}{|C_i|}\sum_{x \in C_i}x$$

初始中心是随机选择的，但之后的每次迭代都会根据当前簇内所有点重新计算均值。

---

### 第2题
**答案：C**

**解析**：
K-means的缺点包括：
- ✓ 需要预先指定k值
- ✓ 对初始中心敏感（不同初始化可能得到不同结果）
- **✗ 计算复杂度高**：实际上K-means计算复杂度是 $O(nkt)$，相对较低
- ✓ 只能发现球形（凸形）簇

K-means正是因为计算效率高才被广泛使用。

---

### 第3题
**答案：B**

**解析**：
闵可夫斯基距离：$dist = \left(\sum_{u=1}^{n}|x_{iu} - x_{ju}|^p\right)^{\frac{1}{p}}$

| p值 | 名称 |
|-----|------|
| p=1 | 曼哈顿距离（城市街区距离） |
| **p=2** | **欧氏距离** |
| p=∞ | 切比雪夫距离 |

---

### 第4题
**答案：A**

**解析**：
DBSCAN的特点：
- **✓ 自动确定簇的数量**：根据密度自动发现簇
- ✗ 可以发现**任意形状**的簇，不只是球形
- ✗ 对噪声**不敏感**，可以自动识别噪声点
- ✗ 不需要预先指定k值

DBSCAN只需要指定两个参数：$\epsilon$（邻域半径）和 MinPts（最小点数）。

---

### 第5题
**答案：B**

**解析**：
层次聚类两种策略：
- **AGNES (Agglomerative Nesting)**：自底向上的**合并**方法
  - 从每个点作为一个簇开始
  - 逐步合并最近的两个簇
  
- **DIANA (Divisive Analysis)**：自顶向下的**分裂**方法
  - 从所有点作为一个簇开始
  - 逐步分裂

---

### 第6题
**答案：B**

**解析**：
聚类是典型的**无监督学习**任务：
- 训练数据没有标签
- 目标是发现数据的内在结构
- 自动将相似样本归为一组

与之对比，分类是有监督学习（需要标签）。

---

### 第7题
**答案：A**

**解析**：
欧氏距离公式：$d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$

对于点 $(1, 2)$ 和 $(4, 6)$：

$$d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

## 判断题答案

### 第8题
**答案：正确 ✓**

**解析**：
K-means的目标函数是**簇内误差平方和（SSE）**：

$$E = \sum_{i=1}^{k}\sum_{x \in C_i}||x - \mu_i||^2$$

每次迭代包含两步：
1. **划分步**：将样本分配到最近的中心 → SSE不增
2. **更新步**：计算新的均值向量 → SSE不增

因此每次迭代SSE单调不增，这保证了算法收敛。

---

### 第9题
**答案：正确 ✓**

**解析**：
DBSCAN是基于密度的聚类算法：
- 只需要指定 $\epsilon$ 和 MinPts
- 簇的数量由算法自动确定
- 根据数据的密度分布自然形成簇

这是DBSCAN相对于K-means的优势之一。

---

### 第10题
**答案：错误 ✗**

**解析**：
K-means**不一定**能找到全局最优解：

1. **对初始中心敏感**：不同的初始化可能导致不同的结果
2. **可能陷入局部最优**：算法只保证收敛，不保证全局最优

解决方法：
- 多次随机初始化，选择最好的结果
- 使用K-means++进行更好的初始化

---

### 第11题
**答案：正确 ✓**

**解析**：
聚类的核心目标：
- **簇内相似度高**：同一簇中的样本尽可能相似（紧凑）
- **簇间相似度低**：不同簇的样本尽可能不同（分离）

这也是各种聚类评价指标的基础。

---

### 第12题
**答案：正确 ✓**

**解析**：
层次聚类生成一棵**树状结构（dendrogram）**：

- 从叶节点（每个样本）到根节点（所有样本）
- 通过在不同层次"切割"可以得到不同数目的簇
- 因此可以生成从1到n（样本数）的任意数目的聚类结果

这是层次聚类的一大优势。

## 计算题答案

### 计算题 1

**数据**：$A(1, 1)$, $B(2, 1)$, $C(4, 3)$, $D(5, 4)$

**(1) 计算所有点对的欧氏距离**

$$d(A, B) = \sqrt{(2-1)^2 + (1-1)^2} = \sqrt{1} = 1$$

$$d(A, C) = \sqrt{(4-1)^2 + (3-1)^2} = \sqrt{9 + 4} = \sqrt{13} ≈ 3.61$$

$$d(A, D) = \sqrt{(5-1)^2 + (4-1)^2} = \sqrt{16 + 9} = \sqrt{25} = 5$$

$$d(B, C) = \sqrt{(4-2)^2 + (3-1)^2} = \sqrt{4 + 4} = \sqrt{8} ≈ 2.83$$

$$d(B, D) = \sqrt{(5-2)^2 + (4-1)^2} = \sqrt{9 + 9} = \sqrt{18} ≈ 4.24$$

$$d(C, D) = \sqrt{(5-4)^2 + (4-3)^2} = \sqrt{1 + 1} = \sqrt{2} ≈ 1.41$$

**距离矩阵**：

|   | A | B | C | D |
|---|---|---|---|---|
| A | 0 | 1 | 3.61 | 5 |
| B | 1 | 0 | 2.83 | 4.24 |
| C | 3.61 | 2.83 | 0 | 1.41 |
| D | 5 | 4.24 | 1.41 | 0 |

**(2) 层次聚类（单链接）合并过程**

**初始**：4个簇 {A}, {B}, {C}, {D}

**Step 1**：找最小距离 → $d(A,B) = 1$
- 合并 {A} 和 {B} → {A,B}
- 剩余簇：{A,B}, {C}, {D}

**Step 2**：计算新距离
- $d(\{A,B\}, C) = \min(d(A,C), d(B,C)) = \min(3.61, 2.83) = 2.83$
- $d(\{A,B\}, D) = \min(d(A,D), d(B,D)) = \min(5, 4.24) = 4.24$
- $d(C, D) = 1.41$

找最小距离 → $d(C,D) = 1.41$
- 合并 {C} 和 {D} → {C,D}
- 剩余簇：{A,B}, {C,D}

**Step 3**：
- $d(\{A,B\}, \{C,D\}) = \min(d(A,C), d(A,D), d(B,C), d(B,D))$
- $= \min(3.61, 5, 2.83, 4.24) = 2.83$

合并 → {A,B,C,D}

**合并树**：

```
        {A,B,C,D}
        /       \
    {A,B}      {C,D}
    /   \      /   \
   A     B    C     D
```

**(3) 分成2个簇的结果**

在第2层切割：
- **簇1**：{A, B} = {$(1,1)$, $(2,1)$}
- **簇2**：{C, D} = {$(4,3)$, $(5,4)$}

### 计算题 2

**数据**：$x_1=(0,0)$, $x_2=(1,0)$, $x_3=(0,1)$, $x_4=(10,10)$, $x_5=(11,10)$, $x_6=(10,11)$

**初始中心**：$\mu_1=(0,0)$，$\mu_2=(10,10)$

**(1) 第一轮迭代**

**划分**：计算每个点到两个中心的距离

| 点 | 到$\mu_1$的距离 | 到$\mu_2$的距离 | 分配到 |
|---|---|---|---|
| $x_1(0,0)$ | 0 | $\sqrt{200}≈14.14$ | $C_1$ |
| $x_2(1,0)$ | 1 | $\sqrt{181}≈13.45$ | $C_1$ |
| $x_3(0,1)$ | 1 | $\sqrt{181}≈13.45$ | $C_1$ |
| $x_4(10,10)$ | $\sqrt{200}≈14.14$ | 0 | $C_2$ |
| $x_5(11,10)$ | $\sqrt{221}≈14.87$ | 1 | $C_2$ |
| $x_6(10,11)$ | $\sqrt{221}≈14.87$ | 1 | $C_2$ |

$C_1 = \{x_1, x_2, x_3\}$，$C_2 = \{x_4, x_5, x_6\}$

**更新中心**：

$$\mu_1 = \frac{(0,0)+(1,0)+(0,1)}{3} = \left(\frac{1}{3}, \frac{1}{3}\right) ≈ (0.33, 0.33)$$

$$\mu_2 = \frac{(10,10)+(11,10)+(10,11)}{3} = \left(\frac{31}{3}, \frac{31}{3}\right) ≈ (10.33, 10.33)$$

**(2) 第二轮迭代**

**划分**：使用新中心

| 点 | 到$\mu_1$的距离 | 到$\mu_2$的距离 | 分配到 |
|---|---|---|---|
| $x_1(0,0)$ | $\sqrt{0.22}≈0.47$ | $\sqrt{213.6}≈14.62$ | $C_1$ |
| $x_2(1,0)$ | $\sqrt{0.56}≈0.75$ | $\sqrt{193.6}≈13.91$ | $C_1$ |
| $x_3(0,1)$ | $\sqrt{0.56}≈0.75$ | $\sqrt{193.6}≈13.91$ | $C_1$ |
| $x_4(10,10)$ | $\sqrt{187.1}≈13.68$ | $\sqrt{0.22}≈0.47$ | $C_2$ |
| $x_5(11,10)$ | $\sqrt{207.1}≈14.39$ | $\sqrt{0.56}≈0.75$ | $C_2$ |
| $x_6(10,11)$ | $\sqrt{207.1}≈14.39$ | $\sqrt{0.56}≈0.75$ | $C_2$ |

簇划分不变！

**更新中心**：中心也不变

**(3) 收敛分析**

**第二轮迭代后**，簇划分与第一轮相同，因此中心也相同。

**算法收敛！**

**最终结果**：
- **簇1**：$\{x_1, x_2, x_3\} = \{(0,0), (1,0), (0,1)\}$，中心$(0.33, 0.33)$
- **簇2**：$\{x_4, x_5, x_6\} = \{(10,10), (11,10), (10,11)\}$，中心$(10.33, 10.33)$

### 计算题 3

**数据**：$A(0,0)$, $B(3,0)$, $C(0,4)$

**(1) 计算三种距离**

**曼哈顿距离**（$p=1$）：$d_1 = |x_1-x_2| + |y_1-y_2|$

$$d_1(A,B) = |0-3| + |0-0| = 3$$
$$d_1(A,C) = |0-0| + |0-4| = 4$$
$$d_1(B,C) = |3-0| + |0-4| = 7$$

**欧氏距离**（$p=2$）：$d_2 = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$

$$d_2(A,B) = \sqrt{9+0} = 3$$
$$d_2(A,C) = \sqrt{0+16} = 4$$
$$d_2(B,C) = \sqrt{9+16} = 5$$

**切比雪夫距离**（$p=\infty$）：$d_\infty = \max(|x_1-x_2|, |y_1-y_2|)$

$$d_\infty(A,B) = \max(3, 0) = 3$$
$$d_\infty(A,C) = \max(0, 4) = 4$$
$$d_\infty(B,C) = \max(3, 4) = 4$$

**汇总**：

| 点对 | 曼哈顿 | 欧氏 | 切比雪夫 |
|------|--------|------|----------|
| A-B | 3 | 3 | 3 |
| A-C | 4 | 4 | 4 |
| B-C | **7** | **5** | **4** |

**(2) 三种距离的特点比较**

| 距离 | 特点 | 适用场景 |
|------|------|----------|
| 曼哈顿 | 只能沿坐标轴移动 | 城市街区、棋盘 |
| 欧氏 | 直线距离 | 最常用，几何距离 |
| 切比雪夫 | 取最大维度差异 | 国际象棋王的移动 |

**关系**：对于任意两点，总有 $d_\infty \leq d_2 \leq d_1$

在B-C这个例子中：$4 \leq 5 \leq 7$ ✓
