# 第 6 章：支持向量机 (SVM)

## 一、核心概念详解

### 1.1 基本思想

支持向量机（Support Vector Machine, SVM）是一种强大的监督学习算法，主要用于分类任务。

**核心目标**：找到一个超平面，将不同类别的样本分开，并使**间隔最大化**。

### 1.2 超平面与间隔

#### 超平面的表示

在样本空间中，划分超平面可以表示为：

$$w^Tx + b = 0$$

其中：
- $w = (w_1, w_2, ..., w_d)$ 是法向量，决定超平面方向
- $b$ 是位移项，决定超平面位置

#### 样本到超平面的距离

样本点 $x$ 到超平面的距离：

$$r = \frac{|w^Tx + b|}{||w||}$$

其中 $||w|| = \sqrt{w_1^2 + w_2^2 + ... + w_d^2}$ 是 $w$ 的 L2 范数。

#### 间隔 (Margin) ⭐

假设超平面能正确分类所有样本，即：

$$\begin{cases} w^Tx_i + b \geq +1, & y_i = +1 \\ w^Tx_i + b \leq -1, & y_i = -1 \end{cases}$$

可以统一写成：$y_i(w^Tx_i + b) \geq 1$

距离超平面最近的样本点使上式等号成立，它们被称为**支持向量**。

两个异类支持向量到超平面的距离之和称为**间隔**：

$$\gamma = \frac{2}{||w||}$$

```
        |        /    |
  + +   | + +   /  +  |  + +
    + + |   + /     + |
--------+----/--------+----- 超平面
    - - |  /  - -     |
  - -   |/      -     | - -
        /             |
       /|             |
       间隔
```

### 1.3 SVM的最优化目标

**目标**：最大化间隔

$$\max_{w,b} \frac{2}{||w||}$$

等价于：

$$\min_{w,b} \frac{1}{2}||w||^2$$

约束条件：$y_i(w^Tx_i + b) \geq 1, \quad i = 1, 2, ..., m$

这是一个**凸二次规划问题**。

## 二、对偶问题与KKT条件

### 2.1 为什么引入对偶问题？

1. **简化计算**：对偶问题更容易求解
2. **引入核函数**：对偶形式中只涉及样本的内积，便于使用核技巧
3. **理论价值**：揭示问题的本质结构

### 2.2 拉格朗日乘子法

引入拉格朗日乘子 $\alpha_i \geq 0$，得到拉格朗日函数：

$$L(w, b, \alpha) = \frac{1}{2}||w||^2 - \sum_{i=1}^{m}\alpha_i[y_i(w^Tx_i + b) - 1]$$

### 2.3 对偶问题

对 $w$ 和 $b$ 求偏导并令其为0：

$$w = \sum_{i=1}^{m}\alpha_i y_i x_i$$

$$0 = \sum_{i=1}^{m}\alpha_i y_i$$

代入得到对偶问题：

$$\max_{\alpha} \sum_{i=1}^{m}\alpha_i - \frac{1}{2}\sum_{i=1}^{m}\sum_{j=1}^{m}\alpha_i\alpha_j y_i y_j x_i^T x_j$$

约束条件：$\alpha_i \geq 0$，$\sum_{i=1}^{m}\alpha_i y_i = 0$

### 2.4 KKT条件

KKT（Karush-Kuhn-Tucker）条件是最优解必须满足的条件：

$$\begin{cases} \alpha_i \geq 0 \\ y_i(w^Tx_i + b) - 1 \geq 0 \\ \alpha_i[y_i(w^Tx_i + b) - 1] = 0 \end{cases}$$

**关键性质**：
- 对于 $\alpha_i > 0$ 的样本，必有 $y_i(w^Tx_i + b) = 1$，即该样本位于间隔边界上（**支持向量**）
- 对于 $\alpha_i = 0$ 的样本，不参与决策

**结论**：最终模型只与支持向量有关！

## 三、核函数 (Kernel Functions) ⭐

### 3.1 线性不可分问题

当样本在原始空间中线性不可分时，可以将其映射到**高维特征空间**，使其线性可分。

**示例**：
- 原始空间：$x = (x_1, x_2)$（二维）
- 映射后：$\phi(x) = (x_1^2, \sqrt{2}x_1x_2, x_2^2)$（三维）

### 3.2 核技巧 (Kernel Trick)

在对偶问题中，只涉及内积 $x_i^Tx_j$。

定义核函数：

$$\kappa(x_i, x_j) = \phi(x_i)^T\phi(x_j)$$

**核技巧**：不需要显式地计算映射 $\phi(x)$，只需计算核函数值即可。

### 3.3 常用核函数

| 核函数 | 表达式 | 特点 |
|--------|--------|------|
| 线性核 | $\kappa(x_i, x_j) = x_i^Tx_j$ | 无映射 |
| 多项式核 | $\kappa(x_i, x_j) = (x_i^Tx_j + 1)^d$ | 映射到有限维 |
| 高斯核/RBF | $\kappa(x_i, x_j) = \exp\left(-\frac{||x_i-x_j||^2}{2\sigma^2}\right)$ | 映射到无穷维 |
| 拉普拉斯核 | $\kappa(x_i, x_j) = \exp\left(-\frac{||x_i-x_j||}{\sigma}\right)$ | 抗噪声 |
| Sigmoid核 | $\kappa(x_i, x_j) = \tanh(\beta x_i^Tx_j + \theta)$ | 类神经网络 |

**高斯核（RBF核）**是最常用的核函数：
- $\sigma$ 越小，映射维度越高，模型越复杂
- $\sigma$ 越大，模型越简单

## 四、软间隔与正则化

### 4.1 软间隔 (Soft Margin)

**问题**：现实中很难找到完美分割的超平面

**解决**：允许某些样本不满足约束条件

引入**松弛变量** $\xi_i \geq 0$：

$$y_i(w^Tx_i + b) \geq 1 - \xi_i$$

新的优化目标：

$$\min_{w,b,\xi} \frac{1}{2}||w||^2 + C\sum_{i=1}^{m}\xi_i$$

其中 $C > 0$ 是惩罚参数：
- $C$ 越大，对误分类的惩罚越大，间隔越小
- $C$ 越小，对误分类的容忍度越高，间隔越大

### 4.2 合页损失函数 (Hinge Loss) ⭐

软间隔SVM的损失函数可以写成：

$$\min_{w,b} \frac{1}{2}||w||^2 + C\sum_{i=1}^{m}\max(0, 1 - y_i(w^Tx_i + b))$$

其中 $\max(0, 1 - y_i(w^Tx_i + b))$ 就是**合页损失**（Hinge Loss）：

$$\ell_{hinge}(z) = \max(0, 1-z)$$

**性质**：
- 当 $z \geq 1$ 时，损失为0（正确分类且在间隔外）
- 当 $z < 1$ 时，损失为 $1-z$（在间隔内或误分类）

```
损失
  |
2 |*
  | *
1 |  *
  |   *_____
0 |____*____*_____ z
  -1  0  1  2
```

### 4.3 正则化视角

软间隔SVM可以写成正则化形式：

$$\min_{f} \Omega(f) + C\sum_{i=1}^{m}\ell(f(x_i), y_i)$$

其中：
- $\Omega(f) = \frac{1}{2}||w||^2$ 是正则化项（结构风险）
- $\ell$ 是损失函数（经验风险）
- $C$ 控制两者的权衡
