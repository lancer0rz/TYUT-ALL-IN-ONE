# 第 3 章：线性模型 (Linear Models)

## 一、核心概念详解

### 1.1 基本形式

线性模型试图学得一个通过属性的线性组合来进行预测的函数：

$$f(x) = w_1x_1 + w_2x_2 + ... + w_dx_d + b$$

向量形式：

$$f(x) = w^Tx + b$$

其中：
- $w = (w_1, w_2, ..., w_d)$ 是权重向量
- $b$ 是偏置项（截距）
- $x = (x_1, x_2, ..., x_d)$ 是输入特征向量

**线性模型的优点**：
- 形式简单，易于建模
- 可解释性强（$w$ 直观表达各属性的重要性）
- 是更复杂模型的基础

---

### 1.2 线性回归 (Linear Regression)

#### 问题描述
给定数据集 $D = \{(x_1, y_1), (x_2, y_2), ..., (x_m, y_m)\}$，线性回归试图学得：

$$f(x_i) = wx_i + b$$

使得 $f(x_i) \approx y_i$

#### 最小二乘法 (Least Squares Method)

**目标**：最小化均方误差

$$\min_{w,b} E_{(w,b)} = \sum_{i=1}^{m}(f(x_i) - y_i)^2 = \sum_{i=1}^{m}(y_i - wx_i - b)^2$$

**求解方法**：对 $w$ 和 $b$ 分别求偏导，令其为0

$$\frac{\partial E_{(w,b)}}{\partial w} = 2\left(w\sum_{i=1}^{m}x_i^2 - \sum_{i=1}^{m}(y_i - b)x_i\right) = 0$$

$$\frac{\partial E_{(w,b)}}{\partial b} = 2\left(mb - \sum_{i=1}^{m}(y_i - wx_i)\right) = 0$$

**闭式解**：

$$w = \frac{\sum_{i=1}^{m}y_i(x_i - \bar{x})}{\sum_{i=1}^{m}x_i^2 - \frac{1}{m}\left(\sum_{i=1}^{m}x_i\right)^2}$$

$$b = \frac{1}{m}\sum_{i=1}^{m}(y_i - wx_i)$$

其中 $\bar{x} = \frac{1}{m}\sum_{i=1}^{m}x_i$ 是样本均值。

#### 多元线性回归

当有多个属性时，用矩阵形式表示：

$$f(X) = X\hat{w}$$

其中 $\hat{w} = (w; b)$，$X$ 是增广矩阵。

最小二乘解：

$$\hat{w}^* = (X^TX)^{-1}X^Ty$$

### 1.3 对数几率回归 (Logistic Regression) ⭐考核重点

#### 从回归到分类

线性回归输出连续值，如何用于分类？

**思路**：找到一个单调可微函数，将线性回归的输出映射到 $(0, 1)$ 区间，作为属于某类的概率。

#### Sigmoid函数（对数几率函数）⭐必记

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**关键性质**：
- 值域：$(0, 1)$
- $\sigma(0) = 0.5$
- $\sigma(z) + \sigma(-z) = 1$
- 导数：$\sigma'(z) = \sigma(z)(1 - \sigma(z))$

**图像特点**：
- S形曲线
- 当 $z \to +\infty$，$\sigma(z) \to 1$
- 当 $z \to -\infty$，$\sigma(z) \to 0$

```
σ(z)
  1 |        ___________
    |       /
0.5 |------●------
    |     /
  0 |____/
    -------------------- z
         0
```

#### 对数几率回归模型

$$p(y=1|x) = \frac{1}{1 + e^{-(w^Tx + b)}} = \frac{e^{w^Tx + b}}{1 + e^{w^Tx + b}}$$

$$p(y=0|x) = 1 - p(y=1|x) = \frac{1}{1 + e^{w^Tx + b}}$$

#### 对数几率 (Log Odds / Logit)

$$\ln\frac{p(y=1|x)}{p(y=0|x)} = w^Tx + b$$

这就是"对数几率回归"名称的由来。

#### 极大似然估计 ⭐

**似然函数**：

$$L(w, b) = \prod_{i=1}^{m} p(y_i|x_i; w, b)$$

对于二分类问题：

$$L(w, b) = \prod_{i=1}^{m} [p_1^{y_i} \cdot (1-p_1)^{1-y_i}]$$

其中 $p_1 = p(y=1|x) = \sigma(w^Tx + b)$

**对数似然**：

$$\ell(w, b) = \sum_{i=1}^{m} [y_i \ln p_1 + (1-y_i)\ln(1-p_1)]$$

**目标**：最大化对数似然，等价于最小化：

$$\min_{w,b} -\ell(w, b) = \sum_{i=1}^{m} [-y_i \ln p_1 - (1-y_i)\ln(1-p_1)]$$

这就是**交叉熵损失函数**。

**求解**：使用梯度下降或牛顿法等优化算法。

### 1.4 多分类学习策略 ⭐

将多分类问题转化为多个二分类问题。

#### OvO (One-vs-One) 一对一

**方法**：
- 将 $N$ 个类别两两配对
- 产生 $\frac{N(N-1)}{2}$ 个二分类器
- 预测时，每个分类器投票，取票数最多的类

**示例**（3类：A, B, C）：
- 分类器1：A vs B
- 分类器2：A vs C
- 分类器3：B vs C

共3个分类器。

**优缺点**：
- 优点：每个分类器只用两类数据，训练速度快
- 缺点：分类器数量多 $O(N^2)$

#### OvR (One-vs-Rest) 一对其余

**方法**：
- 每次将一个类作为正类，其余所有类作为反类
- 产生 $N$ 个二分类器
- 预测时，取置信度最高的分类器对应的类

**示例**（3类：A, B, C）：
- 分类器1：A vs (B+C)
- 分类器2：B vs (A+C)
- 分类器3：C vs (A+B)

共3个分类器。

**优缺点**：
- 优点：分类器数量少 $O(N)$
- 缺点：类别不平衡问题（正类少，反类多）

#### MvM (Many-vs-Many) 多对多

**方法**：
- 每次将若干类作为正类，若干类作为反类
- 常用技术：纠错输出码 (ECOC)

**ECOC编码**：
- 对 $N$ 个类别进行 $M$ 次划分
- 每次划分将部分类标记为+1，部分标记为-1
- 形成编码矩阵
- 预测时，计算与各类编码的距离

| 对比 | OvO | OvR | MvM |
|------|-----|-----|-----|
| 分类器数量 | $N(N-1)/2$ | $N$ | 自定义 |
| 训练数据量 | 少（2类） | 多（全部） | 可变 |
| 存储开销 | 大 | 小 | 中 |
