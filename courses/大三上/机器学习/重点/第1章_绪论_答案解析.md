### 第4题

## 判断题答案

### 第6题
**答案：正确 ✓**

**解析**：
- 分类任务：预测**离散值**（类别标签），如判断是否垃圾邮件
- 回归任务：预测**连续值**，如预测房价、温度等

这是两种任务最本质的区别。

---

### 第7题
**答案：正确 ✓**

**解析**：
- 假设空间：所有可能假设的集合
- 版本空间：与训练样本一致的假设集合

版本空间是通过训练数据从假设空间中筛选出来的，因此是假设空间的子集。

$$版本空间 \subseteq 假设空间$$

---

### 第8题
**答案：错误 ✗**

**解析**：
在假设空间大小的计算公式 $|H| = \prod_{i=1}^{n}(k_i + 1) + 1$ 中：

- $(k_i + 1)$ 中的 "+1" 代表通配符 "*"（任意值）
- **公式最后的 "+1"** 代表**空假设 $\varnothing$**

题目说的"+1代表任意值"是对公式最后"+1"的错误理解。

---

### 第9题
**答案：错误 ✗**

**解析**：
聚类是**无监督学习**任务，原因是：
- 聚类的输入数据没有标签
- 聚类的目标是发现数据内在的分组结构
- 不需要事先告诉算法每个样本属于哪一类

---

### 第10题
**答案：正确 ✓**

**解析**：
版本空间中的假设必须覆盖所有正例。如果两个正例在某属性上取值不同：
- 正例1：属性A = "值1"
- 正例2：属性A = "值2"

如果假设在该属性上取具体值（如"值1"），则无法覆盖正例2。因此，该属性只能取通配符"*"才能同时覆盖两个正例。

---

## 计算题答案

### 计算题 1

**问题(1)答案**：

假设空间大小的计算：
- 属性A：3个取值 + 1（通配符）= 4
- 属性B：2个取值 + 1（通配符）= 3
- 属性C：4个取值 + 1（通配符）= 5
- 空假设：1

$$|H| = 4 \times 3 \times 5 + 1 = 60 + 1 = \boxed{61}$$

**问题(2)答案**：

不包含空假设和通配符，只考虑合取式假设：
$$|H'| = 3 \times 2 \times 4 = \boxed{24}$$

---

### 计算题 2

**问题(1)答案**：

假设空间大小：
- 天气：3 + 1 = 4
- 温度：3 + 1 = 4
- 风力：2 + 1 = 3
- 空假设：1

$$|H| = 4 \times 4 \times 3 + 1 = 48 + 1 = \boxed{49}$$

**问题(2)答案**：

分析训练数据：
- 正例1：(晴, 热, 弱) → 外出
- 反例2：(晴, 热, 强) → 不外出
- 正例3：(阴, 热, 弱) → 外出

**步骤1**：假设必须覆盖正例1和正例3
- 正例1和正例3的天气不同（晴 vs 阴），所以天气必须是 "*"
- 正例1和正例3的温度相同（热），温度可以是"热"或"*"
- 正例1和正例3的风力相同（弱），风力可以是"弱"或"*"

**步骤2**：假设不能覆盖反例2
- 反例2：(晴, 热, 强)

检查各候选假设：
| 假设 | 是否覆盖正例1 | 是否覆盖正例3 | 是否覆盖反例2 | 是否有效 |
|------|--------------|--------------|--------------|---------|
| (*, 热, 弱) | ✓ | ✓ | ✗ | ✓ |
| (*, 热, *) | ✓ | ✓ | ✓ | ✗ |
| (*, *, 弱) | ✓ | ✓ | ✗ | ✓ |
| (*, *, *) | ✓ | ✓ | ✓ | ✗ |

**版本空间** = $\{(*, 热, 弱), (*, *, 弱)\}$

也可以写成：$\boxed{\{(*, 热, 弱), (*, *, 弱)\}}$

---

### 计算题 3

**问题(1)答案**：

4个布尔属性，每个属性有2个取值：
$$|H| = (2+1) \times (2+1) \times (2+1) \times (2+1) + 1 = 3^4 + 1 = 81 + 1 = \boxed{82}$$

**问题(2)答案**：

给定：
- 正例：(1, 0, 1, 0)
- 反例：(1, 1, 1, 0)

**分析**：正例和反例只在第2个属性上不同（正例是0，反例是1）

版本空间中的假设：
1. 必须覆盖正例(1, 0, 1, 0)
2. 不能覆盖反例(1, 1, 1, 0)

**关键观察**：假设在第2个属性上必须取"0"（不能是"*"或"1"），否则会覆盖反例。

因此版本空间中的假设形式为：(a₁, 0, a₃, a₄)

其中：
- a₁ ∈ {1, *}（2种选择）
- a₃ ∈ {1, *}（2种选择）
- a₄ ∈ {0, *}（2种选择）

版本空间最多包含 $2 \times 2 \times 2 = \boxed{8}$ 个假设。

具体列举：
1. (1, 0, 1, 0)
2. (1, 0, 1, *)
3. (1, 0, *, 0)
4. (1, 0, *, *)
5. (*, 0, 1, 0)
6. (*, 0, 1, *)
7. (*, 0, *, 0)
8. (*, 0, *, *)
