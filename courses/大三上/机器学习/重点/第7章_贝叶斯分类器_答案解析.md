# 第 7 章：贝叶斯分类器 - 答案解析

## 选择题答案

### 第1题
**答案：B**

**解析**：
朴素贝叶斯的核心假设是**属性条件独立性假设**：

$$P(x|c) = \prod_{i=1}^{d}P(x_i|c)$$

即在给定类别的条件下，各属性之间相互独立。

这是"朴素"（Naive）的来源——虽然简单但效果不错。

---

### 第2题
**答案：B**

**解析**：
贝叶斯公式：$P(c|x) = \frac{P(x|c)P(c)}{P(x)}$

各项名称：
- $P(c|x)$：**后验概率** (Posterior)
- $P(x|c)$：**类条件概率/似然** (Likelihood)
- $P(c)$：**先验概率** (Prior)
- $P(x)$：**证据** (Evidence)

后验 = (似然 × 先验) / 证据

---

### 第3题
**答案：B**

**解析**：
**零概率问题**：如果某个属性值在训练集中没有出现过，其概率估计为0，导致整个乘积为0。

**拉普拉斯平滑**：
$$\hat{P}(x_i|c) = \frac{|D_{c,x_i}| + 1}{|D_c| + N_i}$$

分子加1，分母加可能取值数，确保概率不为0。

---

### 第4题
**答案：B**

**解析**：
对于连续属性，朴素贝叶斯通常假设其服从**高斯分布**（正态分布）：

$$P(x_i|c) = \frac{1}{\sqrt{2\pi}\sigma_{c,i}}\exp\left(-\frac{(x_i - \mu_{c,i})^2}{2\sigma_{c,i}^2}\right)$$

参数 $\mu$ 和 $\sigma$ 从训练数据中估计。

这种方法也称为**高斯朴素贝叶斯**。

---

### 第5题
**答案：D**

**解析**：
半朴素贝叶斯分类器包括：
- SPODE (Super-Parent ODE)
- AODE (Averaged ODE)
- TAN (Tree Augmented Naive Bayes)

SVM（支持向量机）是完全不同的分类算法，不属于贝叶斯分类器家族。

---

### 第6题
**答案：B**

**解析**：
贝叶斯决策论：选择使**期望损失最小**的决策。

对于0-1损失函数，最小化期望损失等价于最大化后验概率：

$$h^*(x) = \arg\max_{c} P(c|x)$$

这就是贝叶斯最优分类器。

---

### 第7题
**答案：A**

**解析**：
先验概率估计：

$$P(A) = \frac{|D_A|}{|D|} = \frac{100}{100 + 200} = \frac{100}{300} = \frac{1}{3}$$

类似地，$P(B) = \frac{200}{300} = \frac{2}{3}$

## 判断题答案

### 第8题
**答案：错误 ✗**

**解析**：
虽然朴素贝叶斯假设属性独立，但实践中即使属性相关，它往往仍能取得不错的效果。

原因：
1. 分类只需要比较相对大小，不需要精确概率
2. 属性相关性可能对各类的影响相似
3. 朴素贝叶斯的低方差特性

"朴素"但不"简单"，是机器学习中的经典算法。

---

### 第9题
**答案：正确 ✓**

**解析**：
拉普拉斯平滑公式：

$$\hat{P}(x_i|c) = \frac{|D_{c,x_i}| + 1}{|D_c| + N_i}$$

- 分子：$|D_{c,x_i}| + 1 \geq 0 + 1 = 1 > 0$
- 分母：$|D_c| + N_i > 0$

因此，平滑后的概率估计值一定大于0。

---

### 第10题
**答案：正确 ✓**

**解析**：
- **朴素贝叶斯**：所有属性完全独立
- **半朴素贝叶斯**：允许部分属性之间存在依赖关系

半朴素贝叶斯通过放宽独立性假设，适当考虑属性间的依赖，以期获得更好的分类效果。

---

### 第11题
**答案：错误 ✗**

**解析**：
贝叶斯分类器**不需要**知道真实的概率分布，而是从训练数据中**估计**概率。

- 先验概率：从类别比例估计
- 类条件概率：从属性在各类中的分布估计

这是**生成式模型**的特点：先估计概率分布，再用于分类。

---

### 第12题
**答案：正确 ✓**

**解析**：
朴素贝叶斯天然支持多分类：

$$h_{nb}(x) = \arg\max_{c \in \mathcal{Y}} P(c)\prod_{i=1}^{d}P(x_i|c)$$

只需对所有类别计算后验概率，选择最大的即可，不需要额外的策略（如OvO、OvR）。

## 计算题答案

### 计算题 1

**数据统计**：
- 总样本：8个
- 男：4个（编号1,2,3,8）
- 女：4个（编号4,5,6,7）

**(1) 先验概率**

$$P(男) = \frac{4}{8} = \boxed{0.5}$$

$$P(女) = \frac{4}{8} = \boxed{0.5}$$

**(2) 类条件概率**

**男性样本特征**：
| 编号 | 身高 | 体重 |
|------|------|------|
| 1 | 高 | 重 |
| 2 | 高 | 重 |
| 3 | 高 | 轻 |
| 8 | 矮 | 重 |

$$P(高|男) = \frac{3}{4}$$
$$P(轻|男) = \frac{1}{4}$$

**女性样本特征**：
| 编号 | 身高 | 体重 |
|------|------|------|
| 4 | 矮 | 重 |
| 5 | 矮 | 轻 |
| 6 | 矮 | 轻 |
| 7 | 高 | 轻 |

$$P(高|女) = \frac{1}{4}$$
$$P(轻|女) = \frac{3}{4}$$

**(3) 后验概率与预测**

预测样本：(身高=高，体重=轻)

$$P(男) \times P(高|男) \times P(轻|男) = 0.5 \times \frac{3}{4} \times \frac{1}{4} = 0.5 \times 0.75 \times 0.25 = \boxed{0.09375}$$

$$P(女) \times P(高|女) \times P(轻|女) = 0.5 \times \frac{1}{4} \times \frac{3}{4} = 0.5 \times 0.25 \times 0.75 = \boxed{0.09375}$$

**结果**：两者相等！

如果非要做决策，可以随机选择或使用其他信息。

实际上，$\frac{3}{4} \times \frac{1}{4} = \frac{1}{4} \times \frac{3}{4} = \frac{3}{16}$

**预测结果**：无法区分，两类概率相等 $\boxed{0.09375 = 0.09375}$

### 计算题 2

**属性取值数**：
- 身高：{高, 矮} + "中" = 假设有3个取值
- 体重：{重, 轻} = 2个取值
- 类别：{男, 女} = 2个

**(1) 拉普拉斯平滑后的先验概率**

$$\hat{P}(男) = \frac{4 + 1}{8 + 2} = \frac{5}{10} = \boxed{0.5}$$

$$\hat{P}(女) = \frac{4 + 1}{8 + 2} = \frac{5}{10} = \boxed{0.5}$$

**(2) 计算 $P(身高=中|男)$**

训练集中没有"中"这个取值，即 $|D_{男,中}| = 0$

$$\hat{P}(中|男) = \frac{0 + 1}{4 + 3} = \boxed{\frac{1}{7} ≈ 0.143}$$

注意：分母是男性样本数（4）加上身高的可能取值数（3）

**(3) 预测样本（身高=中，体重=轻）的后验概率**

先计算各类条件概率（拉普拉斯平滑）：

**男性**：
$$\hat{P}(中|男) = \frac{0+1}{4+3} = \frac{1}{7}$$
$$\hat{P}(轻|男) = \frac{1+1}{4+2} = \frac{2}{6} = \frac{1}{3}$$

**女性**：
$$\hat{P}(中|女) = \frac{0+1}{4+3} = \frac{1}{7}$$
$$\hat{P}(轻|女) = \frac{3+1}{4+2} = \frac{4}{6} = \frac{2}{3}$$

**后验计算**：

$$P(男) \times P(中|男) \times P(轻|男) = 0.5 \times \frac{1}{7} \times \frac{1}{3} = \frac{0.5}{21} = \boxed{\frac{1}{42} ≈ 0.0238}$$

$$P(女) \times P(中|女) \times P(轻|女) = 0.5 \times \frac{1}{7} \times \frac{2}{3} = \frac{1}{21} = \boxed{\frac{1}{21} ≈ 0.0476}$$

**预测结果**：女性概率更高，预测为**女** ✓

### 计算题 3

**已知**：
- 发病率：$P(病) = 0.01$，$P(健康) = 0.99$
- 灵敏度：$P(阳|病) = 0.99$
- 特异度：$P(阴|健康) = 0.95$，即 $P(阳|健康) = 0.05$

**(1) 阳性结果下真正患病的概率**

使用贝叶斯公式：

$$P(病|阳) = \frac{P(阳|病) \times P(病)}{P(阳)}$$

首先计算 $P(阳)$（全概率公式）：

$$P(阳) = P(阳|病) \times P(病) + P(阳|健康) \times P(健康)$$
$$= 0.99 \times 0.01 + 0.05 \times 0.99$$
$$= 0.0099 + 0.0495$$
$$= 0.0594$$

然后计算后验概率：

$$P(病|阳) = \frac{0.99 \times 0.01}{0.0594} = \frac{0.0099}{0.0594} = \boxed{0.1667 ≈ 16.7\%}$$

**(2) 结果分析**

**令人惊讶的结论**：即使检测结果为阳性，真正患病的概率只有约 **16.7%**！

**原因分析**（贝叶斯思维）：

1. **先验概率很低**：疾病发病率只有1%，健康者占99%

2. **假阳性影响大**：
   - 1000人中约10人患病，检出 $10 \times 0.99 ≈ 10$ 人
   - 1000人中约990人健康，误报 $990 \times 0.05 ≈ 50$ 人
   - 总阳性约60人，其中真患病只有10人

3. **比例**：$\frac{10}{10+50} ≈ 16.7\%$

**启示**：
- 检测结果阳性≠真正患病
- 先验概率对后验概率影响很大
- 罕见病筛查需要更高特异度的检测方法
- 这解释了为什么需要多次检测确认

**这就是著名的"基率谬误"（Base Rate Fallacy）**：忽视先验概率，只关注条件概率，会导致错误判断。
