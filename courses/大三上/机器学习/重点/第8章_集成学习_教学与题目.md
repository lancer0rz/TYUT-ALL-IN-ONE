# 第 8 章：集成学习 (Ensemble Learning)

## 一、核心概念详解

### 1.1 集成学习的基本思想

**核心理念**：通过组合多个学习器来获得比单一学习器更好的性能。

**通俗理解**："三个臭皮匠，顶个诸葛亮"

### 1.2 "好而不同"原则 ⭐

要使集成有效，需要满足两个条件：

1. **基学习器要有一定的准确性**（"好"）
   - 每个学习器的准确率要高于随机猜测
   
2. **基学习器之间要有差异性**（"不同"）
   - 如果所有学习器完全相同，集成没有意义

**理论分析**：

假设有 $T$ 个基学习器，每个的错误率为 $\epsilon$，且相互独立。

集成学习器通过简单投票的错误率：

$$H(x) = sign\left(\sum_{i=1}^{T}h_i(x)\right)$$

集成错误率：

$$P(H(x) \neq f(x)) = \sum_{k=0}^{\lfloor T/2 \rfloor}\binom{T}{k}(1-\epsilon)^k\epsilon^{T-k}$$

当 $\epsilon < 0.5$ 且 $T \to \infty$ 时，集成错误率趋近于0。

## 二、个体与集成

### 2.1 基学习器的类型

- **同质集成**：基学习器都是同一类型（如都是决策树）
  - 基学习器也称为**弱学习器**
  
- **异质集成**：基学习器是不同类型（如决策树+SVM+神经网络）
  - 基学习器也称为**个体学习器**

### 2.2 集成策略

#### 结合方法

**平均法**（用于回归）：

$$H(x) = \frac{1}{T}\sum_{i=1}^{T}h_i(x)$$

**加权平均法**：

$$H(x) = \sum_{i=1}^{T}w_i h_i(x)$$

其中 $w_i \geq 0$，$\sum_{i=1}^{T}w_i = 1$

**投票法**（用于分类）：

- **绝对多数投票**：获得半数以上票才预测该类，否则拒绝
- **相对多数投票**：预测得票最多的类
- **加权投票**：按学习器权重加权

**学习法**：

- 训练一个元学习器来结合基学习器的输出
- 典型方法：**Stacking**

## 三、Boosting方法

### 3.1 基本思想

**串行**生成基学习器，每个学习器都试图**纠正前一个的错误**。

关注之前被错误分类的样本，给予更高权重。

### 3.2 AdaBoost算法 ⭐

**步骤**：

1. 初始化样本权重：$D_1(i) = \frac{1}{m}$

2. for $t = 1, 2, ..., T$:
   
   a. 使用权重 $D_t$ 训练基学习器 $h_t$
   
   b. 计算加权错误率：
   $$\epsilon_t = \sum_{i=1}^{m}D_t(i)\mathbb{I}(h_t(x_i) \neq y_i)$$
   
   c. 计算学习器权重：
   $$\alpha_t = \frac{1}{2}\ln\frac{1-\epsilon_t}{\epsilon_t}$$
   
   d. 更新样本权重：
   $$D_{t+1}(i) = \frac{D_t(i)}{Z_t} \times \begin{cases} e^{-\alpha_t}, & h_t(x_i) = y_i \\ e^{\alpha_t}, & h_t(x_i) \neq y_i \end{cases}$$
   
   其中 $Z_t$ 是规范化因子

3. 输出：$H(x) = sign\left(\sum_{t=1}^{T}\alpha_t h_t(x)\right)$

**关键点**：
- 错误率低的学习器权重高（$\alpha_t$ 大）
- 被误分的样本权重增加（下次更关注）
- 正确分类的样本权重降低

### 3.3 Boosting的特点

| 特点 | 描述 |
|------|------|
| 训练方式 | 串行 |
| 样本处理 | 调整权重 |
| 偏差-方差 | 主要减少偏差 |
| 过拟合风险 | 较高 |
| 并行性 | 难以并行 |

## 四、Bagging方法

### 4.1 基本思想

**并行**生成基学习器，通过**随机采样**产生多样性。

### 4.2 Bootstrap采样

**自助采样法**：从 $m$ 个样本中有放回地抽取 $m$ 次。

$$P(样本未被抽中) = \left(1 - \frac{1}{m}\right)^m \to \frac{1}{e} ≈ 0.368$$

约36.8%的样本不会出现在采样集中，称为**包外样本 (Out-of-Bag, OOB)**。

### 4.3 Bagging算法

**步骤**：

1. for $t = 1, 2, ..., T$:
   - 使用Bootstrap采样产生训练集 $D_t$
   - 在 $D_t$ 上训练基学习器 $h_t$

2. 结合方式：
   - 分类：投票法
   - 回归：平均法

### 4.4 随机森林 (Random Forest) ⭐

**特点**：Bagging + 决策树 + **随机属性选择**

**与普通Bagging的区别**：
在每个节点划分时，从当前属性集中**随机选择** $k$ 个属性（通常 $k = \log_2 d$），然后从这 $k$ 个中选择最优属性进行划分。

**优点**：
- 进一步增加多样性
- 训练效率高
- 抗过拟合能力强
- 可以并行训练

### 4.5 Bagging的特点

| 特点 | 描述 |
|------|------|
| 训练方式 | 并行 |
| 样本处理 | 有放回采样 |
| 偏差-方差 | 主要减少方差 |
| 过拟合风险 | 较低 |
| 并行性 | 容易并行 |

---

## 五、Boosting vs Bagging

| 对比项 | Boosting | Bagging |
|--------|----------|---------|
| 训练方式 | 串行 | 并行 |
| 样本使用 | 调整权重 | 有放回采样 |
| 学习器权重 | 不同（按性能） | 相同 |
| 关注重点 | 减少偏差 | 减少方差 |
| 典型算法 | AdaBoost, GBDT | 随机森林 |
| 对噪声敏感度 | 高 | 低 |

## 六、多样性增强

### 6.1 为什么需要多样性？

集成学习的效果取决于基学习器的多样性。如果基学习器相同，集成没有意义。

### 6.2 增强多样性的手段

#### 数据样本扰动
- 有放回采样（Bagging）
- 交叉验证划分

#### 输入属性扰动
- 随机选择属性子集（随机森林）
- 随机子空间方法

#### 输出表示扰动
- 对输出标记进行变换
- 翻转随机化

#### 算法参数扰动
- 不同的参数设置
- 随机初始化
