## 三、实验内容

### 3.1 HTML页面结构设计

创建了一个个人信息展示页面，包含以下主要区域：

1. **页面头部（Header）**：包含页面标题和导航菜单
2. **个人简介区域**：展示头像、基本信息表格和个人介绍
3. **技能特长区域**：使用进度条展示各项技能水平
4. **兴趣爱好区域**：使用卡片布局展示爱好
5. **联系方式区域**：包含留言表单
6. **页面底部（Footer）**：版权信息和实时时间显示

### 3.2 HTML标签使用

本实验使用了以下HTML标签：

| 标签类型 | 使用的标签 | 用途 |
|---------|-----------|------|
| 结构标签 | `<header>`, `<section>`, `<footer>`, `<nav>`, `<div>` | 页面布局结构 |
| 标题标签 | `<h1>`, `<h2>`, `<h3>` | 各级标题 |
| 文本标签 | `<p>`, `<span>` | 段落和行内文本 |
| 列表标签 | `<ul>`, `<li>` | 导航菜单 |
| 表格标签 | `<table>`, `<tr>`, `<th>`, `<td>` | 个人信息表格 |
| 表单标签 | `<form>`, `<input>`, `<textarea>`, `<button>`, `<label>` | 联系表单 |
| 媒体标签 | `<img>` | 头像图片 |
| 链接标签 | `<a>` | 导航链接 |

### 3.3 CSS样式设计

#### 3.3.1 CSS选择器使用

```css
/* 标签选择器 */
body { font-family: 'Microsoft YaHei', Arial, sans-serif; }

/* 类选择器 */
.container { max-width: 1200px; margin: 0 auto; }

/* ID选择器 */
#avatar { width: 200px; height: 200px; }

/* 后代选择器 */
.nav a { color: white; text-decoration: none; }

/* 伪类选择器 */
.hobby-card:hover { transform: translateY(-10px); }
```

#### 3.3.2 主要CSS技术

1. **Flexbox布局**：用于导航菜单和个人信息区域的水平排列
2. **Grid布局**：用于兴趣爱好卡片的网格排列
3. **CSS变量**：定义主题颜色，便于统一管理
4. **过渡动画**：使用`transition`实现平滑的交互效果
5. **响应式设计**：使用媒体查询适配不同屏幕尺寸

### 3.4 JavaScript交互功能

#### 3.4.1 实现的功能

1. **实时时间显示**：使用`setInterval`每秒更新页面底部的时间
2. **技能进度条动画**：使用Intersection Observer API实现滚动触发动画
3. **回到顶部按钮**：监听滚动事件，显示/隐藏按钮
4. **表单验证**：
   - 姓名：至少2个字符
   - 邮箱：正则表达式验证格式
   - 电话：可选，验证11位手机号
   - 留言：至少10个字符
5. **平滑滚动**：点击导航链接平滑滚动到对应区域
6. **卡片交互效果**：鼠标悬停和点击效果

## 五、实验总结

### 5.1 收获与体会

1. 通过本实验，深入理解了HTML语义化标签的重要性，合理使用`<header>`、`<section>`、`<footer>`等标签可以提高页面的可读性和可维护性。

2. CSS Flexbox和Grid布局大大简化了页面布局的实现，相比传统的浮动布局更加直观和灵活。

3. JavaScript的DOM操作和事件处理是实现页面交互的核心，合理使用事件委托可以提高性能。

4. 表单验证是用户体验的重要组成部分，实时验证可以及时给用户反馈。

### 5.2 遇到的问题及解决方法

1. **问题**：技能进度条动画在页面加载时就执行，效果不明显
   **解决**：使用Intersection Observer API监测元素进入视口再触发动画

2. **问题**：表单验证错误信息显示位置不统一
   **解决**：使用统一的错误信息容器和CSS样式

3. **问题**：移动端布局错乱
   **解决**：添加响应式媒体查询，针对不同屏幕尺寸调整布局

### 5.3 改进方向

1. 可以添加更多的动画效果，如页面加载动画
2. 可以使用LocalStorage保存用户的留言记录
3. 可以添加暗色主题切换功能
4. 可以优化图片加载，使用懒加载技术
