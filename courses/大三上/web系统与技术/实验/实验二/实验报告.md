#### 3.2.2 RegServlet.java 注册处理

```java
@WebServlet("/RegServlet")
public class RegServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response) 
            throws ServletException, IOException {
        // 1. 获取表单参数
        String username = request.getParameter("username");
        String password = request.getParameter("password");
        String email = request.getParameter("email");
        
        // 2. 检查用户名是否已存在（通过Cookie）
        Cookie[] cookies = request.getCookies();
        // 遍历Cookie检查...
        
        // 3. 创建Cookie保存用户信息
        String userInfo = password + "|" + email;
        Cookie userCookie = new Cookie("user_" + username, URLEncoder.encode(userInfo, "UTF-8"));
        userCookie.setMaxAge(60 * 60 * 24 * 30); // 30天有效期
        response.addCookie(userCookie);
    }
}
```

### 3.4 登出功能实现

```java
@WebServlet("/LogoutServlet")
public class LogoutServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response) 
            throws ServletException, IOException {
        // 1. 使Session失效
        HttpSession session = request.getSession(false);
        if (session != null) {
            session.invalidate();
        }
        
        // 2. 清除"记住我"的Cookie
        Cookie savedUsername = new Cookie("savedUsername", "");
        savedUsername.setMaxAge(0);
        response.addCookie(savedUsername);
    }
}
```

### 3.5 Cookie与Session对比

| 特性 | Cookie | Session |
|------|--------|---------|
| 存储位置 | 客户端浏览器 | 服务器端 |
| 安全性 | 较低，可被篡改 | 较高，存储在服务器 |
| 大小限制 | 约4KB | 无明确限制 |
| 生命周期 | 可设置持久化 | 默认随浏览器关闭 |
| 本实验用途 | 保存用户注册信息、记住用户名 | 保存登录状态 |

## 六、实验总结

### 6.1 收获与体会

1. **Servlet生命周期**：理解了Servlet的init()、service()、destroy()方法的调用时机，以及doGet()和doPost()方法的区别。

2. **Cookie机制**：Cookie存储在客户端，可以设置有效期实现持久化存储。但由于存储在客户端，安全性较低，不适合存储敏感信息。

3. **Session机制**：Session存储在服务器端，通过Session ID（通常通过Cookie传递）来识别用户。相比Cookie更安全，适合存储用户登录状态等敏感信息。

4. **编码问题**：在处理中文时需要注意设置请求和响应的字符编码为UTF-8，Cookie值需要进行URL编码。

### 6.2 遇到的问题及解决方法

1. **问题**：Cookie中的中文乱码
   **解决**：使用URLEncoder/URLDecoder对Cookie值进行编码和解码

2. **问题**：Session在关闭浏览器后失效
   **解决**：这是Session的正常行为，如需持久化可配合Cookie使用

3. **问题**：表单提交后中文参数乱码
   **解决**：在获取参数前设置 `request.setCharacterEncoding("UTF-8")`

### 6.3 改进方向

1. 使用数据库代替Cookie存储用户信息，提高安全性
2. 添加密码加密功能（如MD5、SHA256）
3. 添加验证码功能防止暴力破解
4. 使用Filter实现登录状态检查
