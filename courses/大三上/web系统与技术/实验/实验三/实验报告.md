### 3.2 JSP基本语法使用

#### 3.2.1 JSP指令

```jsp
<%-- 页面指令 --%>
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>

<%-- 导入Java类 --%>
<%@ page import="java.util.Date" %>
<%@ page import="java.text.SimpleDateFormat" %>

<%-- 包含指令 --%>
<%@ include file="includes/header.jsp" %>
```

#### 3.2.2 JSP脚本元素

```jsp
<%-- 声明 --%>
<%!
    private String formatDate(long timestamp) {
        SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
        return sdf.format(new Date(timestamp));
    }
%>

<%-- 脚本片段 --%>
<%
    String username = (String) session.getAttribute("username");
    if (username == null) {
        response.sendRedirect("login.jsp");
        return;
    }
%>

<%-- 表达式 --%>
<p>欢迎，<%= username %>！</p>
```

### 3.3 JSP内置对象使用

| 内置对象 | 类型 | 本实验用途 |
|---------|------|-----------|
| request | HttpServletRequest | 获取表单参数、请求属性 |
| response | HttpServletResponse | 重定向、添加Cookie |
| session | HttpSession | 保存用户登录状态 |
| out | JspWriter | 输出内容到页面 |
| application | ServletContext | 全局应用信息 |

#### doRegister.jsp - 注册处理

```jsp
<%
    // 获取表单参数
    String username = request.getParameter("username");
    String password = request.getParameter("password");
    
    // 验证参数
    if (username == null || username.trim().isEmpty()) {
        response.sendRedirect("register.jsp?error=empty");
        return;
    }
    
    // 保存到Cookie
    String userInfo = password + "|" + email + "|" + nickname;
    Cookie userCookie = new Cookie("user_" + username, URLEncoder.encode(userInfo, "UTF-8"));
    userCookie.setMaxAge(60 * 60 * 24 * 30);
    response.addCookie(userCookie);
%>
```

### 4.3 JSP与Servlet对比

| 方面 | Servlet | JSP |
|------|---------|-----|
| 代码形式 | 纯Java代码 | HTML中嵌入Java |
| 适用场景 | 业务逻辑处理 | 页面展示 |
| 开发效率 | 较低（需手动输出HTML） | 较高（直接编写HTML） |
| 维护性 | 逻辑与展示混合 | 前后端分离更清晰 |

## 六、实验总结

### 6.1 收获与体会

1. **JSP执行原理**：理解了JSP本质上是Servlet，第一次访问时会被翻译成Servlet源文件并编译。

2. **JSP指令**：掌握了page、include、taglib三种指令的使用方法。page指令设置页面属性，include指令实现页面复用。

3. **JSP内置对象**：熟练使用了request、response、session、out等内置对象，了解了它们的作用域和生命周期。

4. **MVC思想**：通过本实验，初步理解了将页面展示（View）和业务逻辑（Controller）分离的重要性。

### 6.2 遇到的问题及解决方法

1. **问题**：include指令包含的文件中变量未定义
   **解决**：确保被包含文件中使用的变量在主页面中已定义

2. **问题**：表单提交后页面乱码
   **解决**：在JSP开头设置 `request.setCharacterEncoding("UTF-8")`

3. **问题**：Session在不同页面之间数据不一致
   **解决**：检查是否在某些页面调用了session.invalidate()

### 6.3 改进方向

1. 使用JSTL标签库替代JSP脚本，提高代码可读性
2. 使用EL表达式简化数据展示
3. 将业务逻辑抽取到JavaBean中，实现更好的代码分离
4. 添加登录状态检查的Filter
