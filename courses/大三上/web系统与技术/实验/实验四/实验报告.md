### 3.6 登录功能改进

#### LoginServlet.java - 使用数据库验证

```java
@WebServlet("/LoginServlet")
public class LoginServlet extends HttpServlet {
    
    private UserDao userDao = new UserDao();
    
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response) {
        // 从数据库验证用户
        User user = userDao.findByUsernameAndPassword(username, password);
        
        if (user == null) {
            outputError(out, "用户名或密码错误！");
            return;
        }
        
        // 登录成功，创建Session
        HttpSession session = request.getSession();
        session.setAttribute("user", user);
        session.setAttribute("username", user.getUsername());
        session.setAttribute("loginTime", System.currentTimeMillis());
        
        // 重定向到欢迎页面
        response.sendRedirect("welcome.jsp");
    }
}
```

### 3.7 JDBC访问数据库步骤

1. **加载驱动**：`Class.forName("com.mysql.cj.jdbc.Driver")`
2. **获取连接**：`DriverManager.getConnection(url, user, password)`
3. **创建Statement**：`conn.prepareStatement(sql)`
4. **执行SQL**：`pstmt.executeQuery()` 或 `pstmt.executeUpdate()`
5. **处理结果**：遍历ResultSet获取数据
6. **关闭资源**：按照ResultSet → Statement → Connection的顺序关闭

### 4.3 Cookie存储 vs 数据库存储对比

| 方面 | Cookie存储（实验二/三） | 数据库存储（实验四） |
|------|------------------------|---------------------|
| 存储位置 | 客户端浏览器 | 服务器端MySQL |
| 安全性 | 低，可被篡改 | 高，数据在服务器 |
| 数据量 | 受限（约4KB） | 无明显限制 |
| 跨设备 | 不支持 | 支持 |
| 持久性 | 依赖浏览器 | 持久存储 |
| 适用场景 | 临时数据、偏好设置 | 用户信息、重要数据 |

## 六、实验总结

### 6.1 收获与体会

1. **JDBC工作原理**：理解了JDBC作为Java与数据库之间的桥梁，通过驱动程序实现与不同数据库的通信。

2. **PreparedStatement**：使用PreparedStatement代替Statement，可以有效防止SQL注入攻击，同时提高执行效率。

3. **资源管理**：数据库连接是有限的资源，必须及时关闭。使用try-finally确保资源释放，或使用try-with-resources语法。

4. **分层架构**：将数据访问逻辑封装到DAO层，使代码更加清晰、可维护。

### 6.2 遇到的问题及解决方法

1. **问题**：数据库连接失败，报"Communications link failure"
   **解决**：检查MySQL服务是否启动，检查连接URL中的主机名和端口

2. **问题**：中文数据乱码
   **解决**：在连接URL中添加`characterEncoding=UTF-8`参数

3. **问题**：驱动类找不到
   **解决**：确保MySQL驱动jar包已添加到项目依赖中

4. **问题**：时区错误
   **解决**：在连接URL中添加`serverTimezone=Asia/Shanghai`参数

### 6.3 改进方向

1. 使用连接池（如Druid、HikariCP）提高数据库连接效率
2. 添加密码加密（如BCrypt）提高安全性
3. 使用MyBatis或JPA简化数据库操作
4. 添加事务管理保证数据一致性
