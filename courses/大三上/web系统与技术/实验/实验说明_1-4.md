## 实验一：HTML/CSS/JavaScript 静态页面

### 实验要求
使用HTML、CSS和JavaScript技术，自行设计并实现：
1. 用户注册页面（register.html）
2. 用户登录页面（login.html）
3. 论坛类网站主页面（index.html）

### 实现内容
- ✅ **index.html**: 技术论坛首页，包含热门话题、最新帖子、技术板块等内容
- ✅ **register.html**: 用户注册页面，包含用户名、密码、确认密码、邮箱等字段
- ✅ **login.html**: 用户登录页面，包含用户名、密码、记住密码等功能
- ✅ **JavaScript验证**: 用户名不能为空、密码至少6位、两次密码一致性验证

### 运行方式
```bash
# 直接在浏览器中打开
cd 实验一
# 打开 index.html, login.html, register.html 任意一个
```

## 实验二：Servlet 与 Cookie 会话管理

### 实验要求
1. 编写 RegServlet.java：接收注册信息，保存用户名和密码到Cookie（1个月）
2. 编写 LoginServlet.java：从Cookie获取注册信息验证登录，登录成功后保存到Session

### 实现内容
- ✅ **RegServlet.java**: 注册Servlet，将用户信息保存到Cookie中（有效期30天）
- ✅ **LoginServlet.java**: 登录Servlet，从Cookie验证用户，成功后创建Session
- ✅ **LogoutServlet.java**: 退出Servlet，清除Session
- ✅ **Cookie格式**: `user_用户名 = 密码|邮箱`

### 运行方式
```bash
cd 实验二
# 使用Maven Tomcat插件运行
/path/to/maven/bin/mvn tomcat7:run

# 或先构建再运行
mvn clean package
mvn tomcat7:run

# 访问地址
http://localhost:8080/register.html
http://localhost:8080/login.html
```

## 实验三：JSP 技术与 Session 管理

### 实验要求
1. 升级 index.html 为 index.jsp，判断Session是否已登录，包含welcome.jsp显示用户信息
2. 升级 register.html 为 register.jsp，判断Cookie是否已注册，提示重新注册会丢失信息

### 实现内容
- ✅ **index.jsp**: 论坛主页，检查Session登录状态，未登录跳转到登录页
- ✅ **welcome.jsp**: 欢迎页面，显示登录用户的用户名
- ✅ **register.jsp**: 注册页面，检查Cookie提示用户已注册
- ✅ **login.jsp**: 登录页面
- ✅ **doRegister.jsp**: 处理注册逻辑，保存到Cookie
- ✅ **doLogin.jsp**: 处理登录逻辑，验证后保存到Session
- ✅ **doLogout.jsp**: 处理退出逻辑，清除Session

### 运行方式
```bash
cd 实验三
mvn clean package
mvn tomcat7:run

# 访问地址
http://localhost:8080/register.jsp
http://localhost:8080/login.jsp
http://localhost:8080/index.jsp
```

## 实验四：JDBC 访问数据库

### 实验要求
1. 创建user表（username, password等字段）
2. 修改RegServlet：保存到数据库，判断用户名是否存在
3. 修改LoginServlet：从数据库验证登录，成功后保存到Session

### 实现内容
- ✅ **DBUtil.java**: 数据库工具类，使用H2内嵌数据库（MySQL兼容模式）
- ✅ **User.java**: 用户实体类
- ✅ **UserDao.java**: 用户数据访问对象，提供增删改查方法
- ✅ **RegServlet.java**: 注册Servlet，保存用户到数据库
- ✅ **LoginServlet.java**: 登录Servlet，从数据库验证用户
- ✅ **数据库**: H2内嵌数据库，自动创建user表和测试数据

### 数据库说明
- 使用H2内嵌数据库（MySQL兼容模式）
- 数据文件存储在项目根目录的 `data/` 文件夹
- 自动创建表结构和测试用户：
  - 用户名：admin / 密码：123456
  - 用户名：test / 密码：123456

### 运行方式
```bash
cd 实验四
mvn clean package
mvn tomcat7:run

# 访问地址
http://localhost:8080/register.html
http://localhost:8080/login.html
http://localhost:8080/welcome.jsp
```

## 常见问题

### Q1: 如何修改端口？
A: 编辑各实验的 `pom.xml`，找到 `tomcat7-maven-plugin` 配置中的 `<port>8080</port>`，修改为其他端口。

### Q2: 实验四的数据库文件在哪里？
A: 在实验四项目根目录下的 `data/` 文件夹，文件名为 `web_experiment.mv.db`

### Q3: 如何清除Cookie测试？
A: 
- 浏览器开发者工具 -> Application -> Cookies -> 删除对应Cookie
- 或使用浏览器隐私模式测试

### Q4: Session过期怎么办？
A: Session默认30分钟过期，过期后会自动跳转到登录页面，重新登录即可。

## 实验演示流程

### 完整测试流程（推荐实验四）

1. **启动项目**
   ```bash
   cd 实验四
   mvn tomcat7:run
   ```

2. **注册新用户**
   - 访问 http://localhost:8080/register.html
   - 填写用户名（如：zhangsan）、密码（至少6位）、邮箱
   - 点击注册，看到成功提示

3. **登录系统**
   - 点击"立即登录"或访问 http://localhost:8080/login.html
   - 输入刚才注册的用户名和密码
   - 勾选"记住密码"（可选）
   - 登录成功跳转到欢迎页面

4. **查看欢迎页面**
   - 显示登录用户的信息
   - 可以退出登录

5. **测试Session**
   - 等待30分钟或关闭浏览器
   - 重新访问欢迎页面，会跳转到登录页

6. **查看数据库**
   - 数据存储在 `data/web_experiment.mv.db`
   - 可以使用H2 Console查看（需要额外配置）
